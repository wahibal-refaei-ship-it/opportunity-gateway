# عقد البيانات والتشغيل

`data/opportunities.json` هو المصدر الرئيسي الوحيد، بإصدار مخطط 2.0.0. يتضمن 20 سجلًا: عشر منح أصلية بمعرّفاتها وعشر دورات بمعرّفات course-001…course-010.

## أهم الحقول

| الحقل | المقصود |
|---|---|
| `type` | scholarship أو course فقط |
| `status` | الحالة في تاريخ الفحص؛ self_paced للدورات |
| `status_scope` | نطاق الجولة أو المتقدم أو البرنامج الذي تنطبق عليه الحالة |
| `deadline` | نوع الموعد، تواريخه، الساعة والمنطقة إن ثبتتا، وملاحظة ثنائية اللغة |
| `course.free_access` | مجانية الدراسة؛ true لكل الدورات المختارة |
| `course.certificate` | وضع الشهادة وتفاصيلها ومصدرها بشكل منفصل |
| `course.duration` | حجم محتوى أو وقت تقديري؛ ليس مهلة تقديم |
| `course.content_languages` | لغات محتوى تأكد وجودها؛ القائمة ليست بالضرورة شاملة |
| `verified_at` | تاريخ فحص المصدر الآلي |
| `human_review` | مراجعة بشرية مستقلة لا تُستنتج من الفحص الآلي |
| `evidence` | روابط رسمية وما تدعمه، مع حدود الفحص عند الحاجة |
| `origin` | ربط المنحة بمعرفها الأصلي أوبيان أن الدورة مضافة |

الحقول النصية المترجمة تستخدم `{ar,en}`. المتطلبات تستخدم `{ar:[...],en:[...]}`. المنح تحمل `course:null`. لا تحوّل null إلى صفر أو تاريخ اليوم.

## الأوامر

```bash
node scripts/validate-opportunities.mjs
node scripts/validate-opportunities.mjs --as-of 2026-10-21
node scripts/build-design-data.mjs
node scripts/weekly-report.mjs
```

الفحص البنيوي بدون شبكة. فاحص Node محلي مخصص لهذا العقد، ولا يستخدم مكتبة JSON Schema خارجية. المخطط المرفق صالح للاستخدام مع أداة JSON Schema تدعم 2020-12 ، مع بقاء قواعد الأعمال مثل 10/10 والمعرّفات في الفاحص المحلي.

الفحص الشبكي الاختياري:

```bash
node scripts/check-links.mjs
```

قد تستجيب المواقع الديناميكية أو المحمية بـ 403 أو 429 أوطلب دخول؛ النتيجة للمراجعة وليست تعديلًا لحالة الفرصة. لا يثبت كود 200 صحة السعر أو الأهلية أو الموعد.

## المعاينة والإنتاج

المولد يحول البيانات إلى صيغة عرض المعاينة فقط. التطبيق النهائي يقرأ JSON المحلي، لا ملف window.OPPORTUNITIES. بعد تصحيح بشري موثق: حدّث المصدر، شغّل الفاحص، ثم المولد، ثم اختبار الواجهة. لا تعدّل ملف المعاينة المشتق يدويًا.
