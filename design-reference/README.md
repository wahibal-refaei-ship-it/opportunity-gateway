# مرجع التصميم التفاعلي — بوّابة الفرص

هذا المجلد مرجع بصري تفاعلي لواجهات **الاستكشاف، والتفاصيل، والمفضلة، وعن البوابة**. يحافظ على الأبيض الدافئ والبنفسجي والذهبي، وخط Cairo ، ورسم البوابة، والعربية والإنجليزية. المساران المعروضان هما المنح الدراسية والدورات المجانية.

## ربط البيانات

يقرأ `index.html` ملف `data.js` ثم `app.js`. يجب أن يعرّف الملف المولّد `window.OPPORTUNITIES` بمصفوفة السجلات المعتمدة في الحزمة. ملف data.js المرفق مولّد من المصدر الرئيسي، وليس قائمة مستقلة للتعديل اليدوي. أعد توليده بواسطة scripts/build-design-data.mjs من جذر الحزمة بعد أي تصحيح معتمد للبيانات.

يستخدم كل سجل `id` و`kind` بقيمة `scholarship` أو `course`، والحقول الحالية مثل `title` و`provider` و`summary` و`location` و`level` و`deadlineLabel` بصيغة `{ ar, en }`. تكون `requirements` و`benefits` مصفوفتين من العناصر ثنائية اللغة. يرتبط العنصر المميز CS50 بالمعرّف `course-001`.

يدعم المرجع هذه الحقول الاختيارية:

| الحقل | العرض |
|---|---|
| `statusLabel: { ar, en }` | حالة الفرصة في البطاقة والتفاصيل. |
| `certificateLabel: { ar, en }` | بيان الشهادة في البطاقة وقسم المزايا. |
| `verificationLabel: { ar, en }` | حالة المعلومات كما وردت في البيانات، دون افتراض مراجعة بشرية. |
| `applicationUrl` | رابط تقديم مطلق باستخدام HTTPS ؛ تُرفض الصيغ الأخرى. |
| `source` | رابط المصدر الرسمي، ويظل ظاهرًا بصورة مستقلة. |

إذا غاب رابط تقديم صالح، يعود الزر إلى رابط المصدر المتاح. تختفي العناصر الاختيارية عند غياب بياناتها. تُعامل النصوص كبيانات ولا تُدرج بوصفها HTML.

## ما ينفذه Antigravity

يُستخدم هذا المرجع للمظهر وتجربة التنقل الأساسية. على Antigravity بناء الصفحات الأربع الفعلية، و Service Worker وسياسة التخزين المؤقت، والفلاتر الإضافية، وفحوص البيانات والمتطلبات الأخرى وفق البرومبت الرئيسي. تنبيه الاتصال الموجود هنا يعرض حالة الشبكة فقط. وجود المرجع لا يثبت اكتمال متطلبات التطبيق النهائي.

افتح المرجع عبر خادم ملفات محلي بعد تجهيز `data.js`. ملف رخصة Cairo موجود في `assets/cairo-OFL.txt`.

يعرض المرجع أيضًا deadlineNote و statusScope و certificateDetails و certificateUrl و contentLanguage في التفاصيل، مع فصل النص القصير للبطاقة عن الشرح الكامل.
