## المهمة وفهم السياق

المهمة هي استكمال ركائز المشروع:
1. **صفحة عن البوابة (`about.html`)**:
   - شرح المشكلة والجمهور المستهدف ونطاق البوابة (منح دراسية ودورات مجانية فقط).
   - توضيح منهجية التحقق ومصادر المعلومات: البيانات لقطة مؤرخة وليست تحديثًا حيًا، وفحص المصادر آلي والمراجعة البشرية معلّقة.
   - التأكيد على سياسة الخصوصية (عدم جمع بيانات، وعدم وجود حسابات أو ملفات تتبع)، والعمل دون اتصال وحدوده (الزيارة الأولى المسبقة لازمة).
2. **PWA والعمل دون اتصال (`manifest.webmanifest`, `service-worker.js`)**:
   - تخزين مسبق للأصول المحلية فقط: الصفحات الأربع (`index.html`, `detail.html`, `favorites.html`, `about.html`)، ملف البيانات `data/opportunities.json`، ملف التنسيق `assets/css/styles.css`، وحدات JavaScript، والخطوط المحلية `assets/fonts/`، والأيقونات `assets/icons/`.
   - عدم تخزين أي روابط خارجية لمصادر التقديم أو منصات الدورات.
   - استخدام بادئة كاش خاصة بالمشروع (`og2-cache-v1`) وحذف النسخ القديمة التابعة للمشروع فقط عند التحديث دون لمس كاشات المشاريع الأخرى أو مسح مفضلة المستخدم.
   - دعم المسارات النسبية لتعمل بسلاسة تحت مجلد مستودع GitHub Pages.
   - شريط تنبيه انقطاع الإنترنت التفاعلي.
3. **التوثيق وسجلات التشغيل**:
   - `README.md` ثنائي اللغة (عربي وإنجليزي).
   - `DEPLOYMENT-RECORD.md` بحالة النشر الحقيقية.
   - `SCHEDULE-RECORD.md` بحالة الجدولة الأسبوعية المستمرة.
