# Brief وكيل ج — عن البوابة و PWA والتوثيق

كل المسارات أدناه من جذر المشروع.

## 1. المهمة

نفّذ صفحة عن البوابة، و PWA والعمل دون اتصال وتحديث Service Worker. جهّز وثائق التشغيل والنشر والجدولة والأدلة، ونفّذ الخطوات التقنية المصرح بها بعد تنسيقها مع قائد التنفيذ. افصل ما اكتمل فعلًا عما ينتظر حسابًا أو مشاركة بشرية.

## 2. السياق

المشروع تطبيق HTML/CSS/ES Modules بأربع صفحات و JSON محلي و 20 سجلًا. الهوية الحالية بنفسجية/بيضاء/ذهبية، وخط Cairo والأصول موجودة محليًا. اقرأ البرومبت والقواعد و`DESIGN-SPEC.md` و`DEPLOYMENT.md` و`SCHEDULED-TASK.md` و`ACCEPTANCE-TESTS.md`.

انتظر قائمة الأصول والمسارات النهائية من أ وب والدمج قبل تثبيت precache. الجدولة المطلوبة أسبوعية مستمرة لإنتاج تقرير فقط، وليست مؤقت محادثة أو مجرد ملف تعليمات. التوثيق يصف التنفيذ الفعلي.

## 3. القيود

- ملكيتك: `about.html` و`manifest.webmanifest` و`service-worker.js` وأيقونات PWA التي يخصصها القائد داخل `assets/icons/`، وخطتك ووثائقك. لا تعدّل CSS والوحدات المشتركة أو الصفحات المملوكة للآخرين بالتزامن.
- خزّن صفحات التطبيق والبيانات والأصول المحلية فقط. لا تخزّن مصادر التقديم أو مواقع الدورات الخارجية.
- استخدم بادئة cache خاصة بالمشروع وإصدارًا واضحًا؛ احذف نسخ المشروع القديمة فقط، ولا تمسح المفضلة أو caches غير التابعة له.
- اشرح أن Offline يحتاج زيارة سابقة ناجحة وأن المحتوى لقطة مؤرخة، ولا تكتب «تحديث حي» أو «تحقق بشري» بلا دليل.
- النشر للمشروع الثاني بمسارات نسبية. لا تدفع إلى المستودع الأول، ولا تقرأ ملفات أسرار أو اعتماد المستخدم.
- لا ترسل رسائل من المهمة المجدولة ولا تعدّل بيانات الفرص. إن تعذر التفعيل أو النشر، سجّل الخطوة المطلوبة والسبب دون ادعاء الإنجاز.
- لا تنشئ تجربة مستخدم أو تأملًا أو فيديو أو Student Review نيابة عن البشر.

## 4. المخرجات

- `plans/agent-c.md` مع Student Review فارغ، وصفحة عن البوابة باللغتين ومعلومات الجمهور والمصادر والخصوصية وحدود الاتصال.
- Manifest و Service Worker وأيقونات محلية، وسياسة تحديث قابلة للاختبار تحت مجلد GitHub Pages.
- `README.md` عربي/إنجليزي يشرح التشغيل والبنية والمصادر والحدود والأوامر الموجودة فعلًا.
- `DEPLOYMENT-RECORD.md` و`SCHEDULE-RECORD.md` بحالات حقيقية وروابط/معرفات فعلية عند توفرها، وإلا تبقى الحقول معلّقة.
- أدلة فعلية في `evidence/agent-c/`، ومقترح إدراجها في `evidence/INDEX.md` الذي يجمعه الدمج، وتسليم يحدد ما اختُبر وما ينتظر التكامل.

## 5. معايير النجاح

تحقق من PWA-01 و OFF-01 إلى OFF-03 و DEPLOY-01 و SCHEDULE-01 ، والأجزاء المناسبة من NAV-01 و UI-01 و I18N-01 و SEC-03. تعمل الصفحات الأربع بعد التخزين الصحيح دون اتصال، ويجلب التحديث نسخة متسقة دون فقد المفضلة. لا تُعد الجدولة مكتملة إلا بدليل تسجيل مستمر وموعد تالٍ وتقرير تجريبي؛ ولا يُعد النشر مكتملًا بلا رابط يعمل.
