# Brief وكيل أ — الاستكشاف والبحث والفلاتر

كل المسارات أدناه من جذر المشروع.

## 1. المهمة

نفّذ صفحة الاستكشاف كاملة، بما يحقق U1 والجزء المتعلق بالعثور على دورة في U2 ، وفق التصميم الأبيض والبنفسجي والذهبي. شغّل الصفحة وافحص نتائج البحث والفلاتر فعليًا، ثم سلّم ما نفذته وأدلته إلى وكيل الدمج.

## 2. السياق

اقرأ `ANTIGRAVITY_MASTER_PROMPT.md` و`PROJECT_RULES.md` و`DESIGN-SPEC.md` و`data/opportunities.schema.json` و`DATA-REVIEW.md` و`SELECTION-AUDIT.md`. لدينا 20 سجلًا: 10 منح و 10 دورات، بلا تصنيف ثالث. صفحات الإنتاج أربع، ومصدر البيانات واحد.

قبل العمل، اتفق مع قائد التنفيذ على واجهة تحميل البيانات، قاموس الترجمة، وظائف الوقت والمفضلة، وعقد مكونات الرأس والبطاقة والفلاتر. أنشئ خطتك من `templates/AGENT-PLAN.md`، وسجّل ما ينتظر تسليمه من الوكلاء الآخرين.

## 3. القيود

- ملكيتك: `index.html` و`assets/js/list.js` وخطتك وأدلة اختباراتك. المالك المعيّن للملفات المشتركة هو وكيل الدمج/قائد التنفيذ؛ لا تكتب بالتوازي في CSS أو `common.js` أو `data.js` أو `i18n.js`.
- قدّم تغييرات الملفات المشتركة كطلب واضح أو patch مقترح إلى مالكها. لا تغيّر بيانات الفرص أو تعيد السجلات المستبعدة.
- HTML دلالي و CSS عادي و JavaScript ES Modules ؛ لا إطار عمل أو CDN. لا تجعل `design-reference/data.js` أو `window.OPPORTUNITIES` مصدرًا للإنتاج.
- أنشئ DOM و`textContent` لبيانات JSON والبحث؛ لا HTML ديناميكي من البيانات ولا inline handlers.
- الفلاتر بمنطق AND. حافظ على الحالة عند تبديل اللغة، ووثّق سياسة تعطيل/تصفير فلاتر الدورات عند اختيار المنح.
- لا تختلق تواريخ أو ساعة إغلاق أو حالة مراجعة بشرية. لا تحوّل `course_specific`/`programme_specific` إلى موعد شامل، ولا مدة الدورة إلى إغلاق.
- Student Review يظل فارغًا حتى يكتب الطالب رأيه. لا تدّع اختبارًا أو تشغيلًا لم يحدث.

## 4. المخرجات

- `plans/agent-a.md`: خطة فعلية بملكية الملفات والتبعيات والمخاطر ومراجعة الطالب الفارغة.
- `index.html` و`assets/js/list.js`: بحث ثنائي اللغة، تصنيفان، مرشحات النوع/المستوى/المجال/البلد أو عبر الإنترنت/الحالة/14 أو 30 يومًا، ومرشحات لغة محتوى الدورة والشهادة المجانية المثبتة.
- ترتيب الاسم/أقرب موعد معلوم/أحدث فحص، وشارات مرشحات، وعدد صحيح، وإعادة ضبط وحالة فارغة.
- أدلة فعلية في `evidence/agent-a/` وتسليم موجز يذكر الملفات والاختبارات والعيوب المتبقية وطلبات التغيير المشتركة. لا تكتب تقرير اختبار جماعي بالتزامن مع الوكلاء.

## 5. معايير النجاح

تحقق من DATA-01 و SEARCH-01 و FILTER-01 إلى FILTER-03 و SORT-01 و TIME-01 إلى TIME-04 ، والأجزاء المناسبة من UI-01 و I18N-01 و A11Y-01 و SEC-01. كل نتيجة تطابق البيانات والفلاتر الفعالة. تعمل الاستكشافات على 360px بالعربية والإنجليزية، دون نوع ثالث أو تواريخ مضللة. مرّر النتائج الفعلية و commit إلى الدمج؛ نجاح الجزء لا يساوي اكتمال المشروع.
