# Brief وكيل ب — التفاصيل والمفضلة

كل المسارات أدناه من جذر المشروع.

## 1. المهمة

نفّذ `detail.html` و`favorites.html` بما يحقق U3 و U4 وجانب تفاصيل الدورة في U2. اربطهما بقائمة الاستكشاف وبنفس مكونات الهوية والتنقل واللغة، واختبر الروابط المباشرة والحفظ والتخزين غير السليم.

## 2. السياق

المنتج أربع صفحات فعلية، و 20 سجلًا من `data/opportunities.json`. اقرأ البرومبت والقواعد و`DESIGN-SPEC.md` و`DATA-REVIEW.md` والعقد و`ACCEPTANCE-TESTS.md`. استعمل `detail.html?id=opp-001` نمطًا للروابط؛ معاينة hash مرجع بصري فقط.

نسّق مسبقًا مع القائد بشأن قراءة JSON ، الترجمة، معالجة المواعيد، والتحقق من الروابط ومعرفات المفضلة. فحص المصدر الآلي ليس مراجعة بشرية، ومجانية الدراسة لا تعني مجانية كل شهادة.

## 3. القيود

- ملكيتك: `detail.html` و`favorites.html` و`assets/js/detail.js` و`assets/js/favorites.js` وخطتك وأدلتك. لا تعدّل CSS أو الوحدات المشتركة بالتزامن؛ أرسل طلب التغيير لمالكها.
- لا تعدّل JSON لتناسب الصفحة، ولا تغيّر `human_review` من pending. لا تضف حقولًا عامة بموعد مفترض.
- تعامَل بأمان مع query و id ؛ اعرض النص عبر DOM و`textContent`. اسمح فقط بروابط HTTPS بلا بيانات اعتماد، وفق وظيفة مشتركة يراجعها الدمج.
- LocalStorage يحفظ المعرفات فقط، مع تحقق من البنية ووجود المعرف. لا تستبدل التحقق بقراءة كائنات موثوقة من التخزين.
- لا تضف حسابات أو Backend أو إرسال طلب للجهة أو رفع ملفات. يخرج التقديم عبر رابط الجهة الرسمي.
- لا تعرض `not_stated` على أنها شهادة مجانية، ولا تسمِّ شارة التعلم شهادة مهنية. حافظ على لغة محتوى الدورة مستقلة عن AR/EN.
- لا تكتب موافقة الطالب أو نتائج اختبار أو مراجعة بشرية غير حاصلة.

## 4. المخرجات

- خطة `plans/agent-b.md` وفق القالب، مع Student Review فارغ.
- الصفحتان ووحدتاهما، ومعلومات كاملة تشمل الأهلية والتمويل/التكلفة والمتطلبات والنطاق والمصدر والتقديم والموعد وتاريخ الفحص.
- عرض مناسب لحقول الشهادة واللغة والمدة، وحالة معرف خاطئ، وفرص مرتبطة من البيانات نفسها.
- مفضلة مستمرة، عداد وأزرار و`aria-pressed` متزامنة، حالة فارغة، ومعالجة رفض/فساد التخزين.
- أدلة فعلية في `evidence/agent-b/`، وتقرير تسليم للدمج بالـ commit والنتائج والقيود وطلبات تعديل الوحدات المشتركة.

## 5. معايير النجاح

تحقق من NAV-01 و DATA-03 و DETAIL-01 و COURSE-01 و FAV-01 و FAV-02 و TIME-02 و TIME-03 ، والأجزاء المناسبة من I18N-01 و A11Y-01 و SEC-01 و SEC-02. يفتح الرابط المباشر تفاصيل السجل الصحيح؛ لا ينهار عند معرف خاطئ أو تخزين تالف. المفضلة لا تُفقد بإعادة التحميل أو تبديل اللغة، ومعلومات المصدر والمراجعة والشهادة صادقة.
